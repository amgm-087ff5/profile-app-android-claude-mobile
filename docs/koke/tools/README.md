# Koke の苔の模型

`KokeMossShaders.kt` の AGSL(MOSS)を Skia(skia-python)で CPU 実行し、平らな部品に苔が生えた所を PNG にして見本の写真と見比べる。

```
pip install --break-system-packages skia-python pillow
python3 docs/koke/tools/koke.py --out <出力フォルダ>
```

出力:
- `button.png`: 主ボタン(300x56dp)の左上の角に群れ。上から view.y = -0.8 / 0 / +0.8(画面の上・中・下にあるとき)、押した(指が群れの中)、生える途中 growth=0.4
- `card.png`: 名刺(340x200dp)の右下の角と下の辺に群れ。並びは同じ

部品の面は黒い濡れた岩の簡単な見本(角の欠けた多角形 + ファセット + 薄い側面。本物は UI 担当の部品)。
- `*_zoom.png`: 各状態の苔の範囲を 3 倍に拡大して横に並べたもの

dp は 2.625(1080px 幅の端末)。群れの置き方(角丸の 45 度の点を基準にする)と描く矩形の求め方は `KokeMoss.kt` と同じ。

## シェーダーの元

`src/koke_moss.agsl` が元。編集したら Kotlin に書き出す:

```
python3 docs/koke/tools/src/gen.py
```

(`app/src/main/java/com/example/businesscard/ui/koke/KokeMossShaders.kt` を上書きする。`$` と `"""` は使えない)

## 描き方のあらまし

1. 群れの場 `field`: 群れごとに「縁に沿った距離 / spread(向きによって伸び縮みし、角の両辺へ非対称に伸びる)」「内側への距離 / depth」「外へのはみ出し / 10dp」を合わせた遠さ q(0 = 芯、1 = 縁)。q から丸いクッションの高さを作り、雑音の塊(2〜4 個の小さな盛り上がり)を足す。押した所はへこむ。
2. 株 `tuftLayer` を 4 層(奥 → 手前、格子 2.6 / 3.8 / 5.0 / 6.2dp)。奥の層は群れの芯に小さく詰まり、手前の層は縁と塊の上に大きく、葉が長く不揃いに垂れる。株ごとに大きさ・葉の本数(8〜16)・葉ごとの長さと欠け・巻き・明るさ・色をばらつかせる。株の根元の q は、画素での q とその傾きから見積もる(場を株ごとに計算しない = 軽い)。q で生える時刻(芯から縁へ)と、押されたときの沈み・倒れ(指から離れる向き)を決める。
3. 光は左上から一つ。群れの起伏・塊・株の丸みを合わせた向きで陰影。塊の間の谷と奥の層は暗い。手前の株が奥に落とす影、群れの縁の葉先の透ける黄緑、葉の中心線のつや、葉先の水滴(下の葉が透け、左上に鋭い光。押すと強く光る)。
4. 見る向き(view): 群れの上面を 1.2dp、株の層を奥 0.8dp 〜 手前 2.6dp、画面の中の位置と逆向きにずらす(高い株ほど手前にある)。影はずらさない。
5. 株のすき間を埋める黒緑は群れの密な所だけ(縁は株だけでほつれる。半透明のにじみは作らない)。平らな面の影は、群れの密な芯を右下へずらしたものと、わずかに右下の接地の暗がりだけ(左・上には出ない)。生えかけ(growth < 0.45)では影も埋めも無く、小さな株が点在するだけ。苔の外は影だけ返して早く終わる。

重さ(CPU の skia-python で、名刺 + ボタンの苔の範囲): v7(3 層)を 1 として約 1.26。
